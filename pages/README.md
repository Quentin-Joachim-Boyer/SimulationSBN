# Pages de visualisation archivées

Pages autonomes (à ouvrir dans un navigateur) qui rejouent une population mesurée, trois
scènes de 300 pas. Exception à la règle « aucun résultat dans git », décidée par Quentin
le 15 novembre 2026 pour pouvoir les consulter plus tard. Chacune se régénère à
l'identique par `python experiments/monde_dechet/voir.py --regime <régime>` après
l'expérience correspondante (graine 0, population 0).

| `monde_2d_saisons-directions_100000pas_pop0.html` | la même, prolongée à 100 000 pas (cinq scènes) | `journal/2026-11-15_saisons-directions.md` |
