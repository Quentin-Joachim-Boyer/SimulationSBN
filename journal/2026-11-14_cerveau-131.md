# Architecture entrée / cerveau / moteur 1/3/1 (dimension 5)

Écrit avant de lancer l'expérience ; la partie « Résultat » est remplie après.

## Pourquoi

Dans l'expérience précédente, le contexte n'était donné qu'à l'état initial et le
moteur pouvait s'entretenir seul : l'évolution mémorisait le contexte dans le moteur,
sans nœud de contrôle. Quentin propose de séparer les rôles.

## Protocole

- Agent : SBN de dimension 5 à topologie contrainte.
  - Nœud 0, entrée : imposée par le contexte pendant toute la vie de l'agent. Dans le
    formalisme, c'est une boucle de poids 1 sans arc entrant, donc un nœud de contrôle
    par construction.
  - Nœuds 1 à 3, cerveau : reçoivent l'entrée et le cerveau.
  - Nœud 4, moteur : lit le cerveau, sans boucle ni retour vers le cerveau.
  - 15 poids évoluent (3 entrée-cerveau, 9 cerveau-cerveau, 3 cerveau-moteur), dans
    [-3, 3] (borne de la dimension 4, celle des nœuds du cerveau).
- État initial : entrée selon le contexte, premier nœud du cerveau allumé (sans quoi le
  réseau reste éteint quand l'entrée vaut 0), le reste éteint.
- Contexte A (entrée 0) : le moteur doit osciller avec la période 2 aux pas 3 à 8, les
  deux phases étant acceptées. Contexte B (entrée 1) : le moteur doit rester allumé aux
  pas 3 à 8. Chaque contexte demande donc une dynamique différente.
- Régimes, sélection et effectifs comme dans l'expérience précédente : fixe (A) ou
  alterné (5 générations par contexte), fitness exp(5 × score), 12 populations de 300
  individus, 600 générations, 0,1 mutation par individu, départ uniforme.
- Mesures, sur la dynamique complète :
  - scission SBN : la face « entrée = 1 » est-elle encore un SBN (sens PSBN) ?
  - contrôle interne : la décomposition PTBN la plus fine a-t-elle plus de deux
    feuilles, c'est-à-dire un nœud du cerveau qui garde sa valeur sur une face ?
  - scores dans A et B.
- Modèle nul : 20 000 génotypes uniformes de même architecture (estimation, pas compte exact).

## Hypothèses

1. Le régime alterné fait baisser la part de scissions SBN sous le modèle nul : pour
   allumer le moteur en permanence quand l'entrée vaut 1, des poids d'entrée positifs
   sont le plus simple, et ils sortent du cadre SBN (la face n'a plus 000 comme point fixe).
2. Sur le contrôle interne, pas de prédiction : l'entrée étant maintenue, rien n'oblige
   le cerveau à mémoriser. Mesure exploratoire.

Réfutation de 1 : part de scissions SBN en régime alterné supérieure ou égale au modèle nul.

## Durée limite

Une séance. Abandon si le régime alterné n'atteint pas 0,9 dans les deux contextes.

## Résultat

Hypothèse 1 confirmée (`python experiments/cerveau_131/run.py`, graine 0, moyennes sur
la seconde moitié des simulations).

|                            | Scission SBN | Contrôle interne | Score A | Score B |
|----------------------------|--------------|------------------|---------|---------|
| Modèle nul (20 000 tirages) | 11,43 %     | 9,66 %           | 0,54    | 0,36    |
| Simulation, régime alterné | 3,19 %       | 5,54 %           | 0,97    | 0,97    |
| Simulation, régime fixe    | 13,87 %      | 5,37 %           | 0,99    | 0,41    |

- La tâche est apprise : le régime alterné atteint 0,97 dans les deux contextes.
- En régime alterné, la part d'agents dont la face « entrée = 1 » est un SBN tombe à
  3 %, contre 11 % au modèle nul et 14 % en régime fixe. Dans les populations finales,
  98 % des agents parfaits ont au moins un poids d'entrée positif : l'entrée sert de
  source d'activation, ce qu'un SBN ne permet pas sur cette face.
- Le contrôle interne est à 5 % dans les deux régimes, sous le modèle nul (10 %). La
  sélection l'appauvrit, alternance ou non.

Lecture : tous ces agents sont pluripotents au sens PTBN par construction (l'entrée
est un nœud de contrôle), et l'alternance leur fait bien porter deux dynamiques
distinctes. Mais elle les éloigne du sens PSBN. La distinction PSBN / PTBN du rapport
est donc ce qui sépare les régimes ici.

Limites : une tâche, une graine, pas de test statistique, modèle nul estimé. Le
contexte B récompense un moteur allumé en permanence, ce qui favorise directement les
poids d'entrée positifs : le résultat peut tenir à ce choix.

## Suites possibles

- Contexte B où le moteur doit s'éteindre, ou osciller autrement : l'effet sur la
  scission SBN doit s'inverser ou disparaître si l'explication est la bonne.
- Interdire les poids d'entrée positifs (à la manière des PSBNI), et voir si la tâche
  reste soluble.
- Entrée non maintenue, pour que le cerveau doive mémoriser le contexte.
