# Journal de recherche

Une entrée par expérience, écrite **avant** de la lancer, dans un fichier `AAAA-MM-JJ_titre.md` :

1. **Question** — ce que l'expérience doit trancher.
2. **Hypothèse** — le résultat attendu, et celui qui la réfuterait.
3. **Protocole** — configuration (`experiments/...`), graines, mesure, modèle nul.
4. **Durée limite et critère d'abandon.**
5. **Résultat** — rempli après coup, y compris quand il est négatif.
